# TabTidy 本机同步扩展

适用于 Chrome 与 Edge，使用同一份扩展文件。

1. 先运行 TabTidy 桌面应用。
2. 浏览器打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
3. “加载已解压的扩展”，选择本目录（含 `manifest.json` 的目录）。
4. 在桌面端复制连接码，点击浏览器中的扩展图标，粘贴并同步。

首次同步后会在标签页变化时更新。重新启动桌面应用后，可在此扩展弹窗再次同步。

只读取普通窗口标签页的标题、网址、编号，数据仅发送至本机 `http://127.0.0.1:37843`，以连接码认证。不读取正文、Cookie、历史记录，不采集隐身窗口。连接码存在当前浏览器配置的本地扩展存储中，请勿分享。

0.2.0 支持执行桌面端人工确认的关闭操作。扩展在关闭前重新核对会话、编号、网址和标题；页面变化、跳转中或已关闭的标签页会跳过，并回报逐项结果。勾选本身不会关闭标签页，关闭可能丢失未保存内容。

从旧版升级时，请更新已加载目录中的全部扩展文件，在扩展管理页点击“重新加载”，然后重新同步。也可移除旧扩展，再加载新版目录并连接。桌面端与扩展须一起更新。

打开时间保持未知；实际展示与选择请在桌面应用中操作。
