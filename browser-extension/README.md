# TabTidy 本机同步扩展

适用于 Chrome 与 Edge，使用同一份扩展文件。

1. 先运行 TabTidy 桌面应用。
2. 浏览器打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
3. “加载已解压的扩展”，选择本目录（含 `manifest.json` 的目录）。
4. 在桌面端复制连接码，点击浏览器中的扩展图标，粘贴并同步。

首次同步后会在标签页变化时更新。重新启动桌面应用后，可在此扩展弹窗再次同步。

只读取普通窗口标签页的标题、网址、编号，数据仅发送至 `http://127.0.0.1:37843/tabs`，以连接码认证。不读取正文、Cookie、历史记录，不采集隐身窗口，也不会关闭标签页。连接码存在当前浏览器配置的本地扩展存储中，请勿分享。

打开时间保持未知；实际展示与选择请在桌面应用中操作。
