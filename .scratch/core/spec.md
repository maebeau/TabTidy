# 独立 core

## 已确认的目标

- 个人使用，后续可能接入 Chrome、Edge 或桌面端；本次只实现独立 core。
- 接收标签页清单，识别重复网址和相似标题，输出候选组。
- 同一本书的章节编号、章节名称不同，也可以归入同组。
- 支持打开时间和自然排序，均支持升降序；默认自然降序，不提供字典序。
- 每组保留排序后的首项、预选其余项，供人工调整确认。
- 按时间排序时，如果组内有未知时间或并列时间，不自动预选；未知时间排在末尾，并列保持输入顺序。
- 工具不会关闭标签页或改动浏览器。

## 第一版接口与识别边界

- 无依赖 JavaScript 模块，公开入口为 `analyzeTabs(tabs, options)`；用同一入口验证分组、排序和预选。
- 输入项包括唯一 `id`、字符串 `title`、可选绝对 `url`、可选 `openedAt`（非负整数毫秒时间戳，null/省略表示未知）。
- `options` 为 `sortBy: natural | time`、`direction: asc | desc`，可选 `ignoredNamesByHost` 域名到忽略名称数组的映射，最多 5000 个域名。桌面的命名规则在调用时展开为此映射，管理名称不参与匹配。
- 输出仅包含至少两个标签页的候选组，每组提供原因和附带 `selected` 标记的标签页副本；输入保持不变。
- 网址按完整字符串比较，保留查询参数与片段的差异。
- 标题统一全半角、大小写、空白和标点；仅匹配时弱化阿拉伯数字和常见版本说明，保留原始标题用于输出及排序。
- 支持不规整命名：少量文字增删、文字顺序调整、共同主体文字位置不同，都可因相邻文字重合或足够长的共同连续片段列为候选；同书名前缀后的章节变化仍可归组。
- 仅有短片段、数字或共同版本说明时不应合并无关主体。不同网站也可以因标题相似归组，默认不依赖网站专用配置；用户可按完整域名配置网站名和板块名，仅在匹配时去除独立前后缀或括号标签，保留正文文字及原标题。
- 候选关系可传递，因此一组内的任意两项不一定直接相似；原因只表示组内存在对应关系。
- 自然排序是通用标题排序，不解析中文数字、小说进度或多个数字的业务含义。
- 提供 JSON 示例与命令行入口，方便独立运行和人工检查输出。

## 验收

公开入口的测试覆盖重复网址、数字和版本说明变化、小说章节名变化、文字顺序调整、不同位置的共同主体、无关标题对照、自然/时间升降序、时间未知/并列、输入校验、输入不可变。
