# 将忽略规则移入设置

Status: ready-for-agent
State: closed

规格见 [spec.md](../spec.md)。

## Comments

- 2026-10-18：用户要求新增设置按钮，将忽略规则移入设置。
- 范围：主界面设置入口、原生设置对话框、规则保存结果提示、桌面交互测试和说明。复用现有表单、存储和迁移逻辑；core、扩展及规则文件格式不变。
- 设置默认关闭，从右上角“设置”打开；支持返回按钮及 Esc，焦点限制在对话框内，关闭后返回入口。关闭不清空未保存的填写内容，保存后才应用并重新分组。
- 对话框内容可滚动，最小窗口下返回按钮和保存结果仍可访问；浏览器同步保留编辑内容和焦点，错误与成功提示显示在设置中。
- 验证发现 Electron 原生对话框在末项 Tab 后将焦点短暂交给窗口层级。已向用户说明原因，用户确认后补充 Tab/Shift+Tab 首尾循环，其余键盘行为沿用原生对话框。
- 测试脚本的程序化点击未聚焦入口，导致重载后关闭对话框的焦点恢复断言失败；临时副本按真实交互先聚焦再点击后全部通过。向用户说明并获确认后，同步修正测试写法。
- 30 项基础回归测试通过；正式 Electron 窗口测试通过设置默认关闭、开关与 Esc、Tab/Shift+Tab 首尾循环、关闭恢复入口焦点、草稿保留且不自动保存、保存/错误提示不被同步覆盖、980×640 最小窗口可滚动，以及原有分组/选择/关闭/迁移流程。
- 已生成 Windows 0.2.3 便携包，包内关键桌面文件、core、规则、说明及扩展与源码一致，ZIP 完整性检查通过。Windows 实机 Chrome/Edge 联调未执行。
