# 桌面及扩展版本提示

Status: ready-for-agent
State: closed

## Comments

- 2026-10-18：用户选择先做版本展示与升级提醒，减少桌面与扩展未配套时的误判。
- 设置页显示当前桌面及随包扩展版本，分别读取应用 package.json 与实际扩展目录 manifest.json。扩展同步通过 runtime.getManifest() 上报正在运行的版本，桌面按来源显示；版本字段可省略，旧扩展显示未知，不猜测版本。
- 按最多四段数值比较运行版本与随包版本。低版本或未知版本显示独立侧栏提示及打开扩展文件夹入口，说明替换原目录文件、在对应浏览器重新加载并同步，仅同步不会升级。相同或高版本不提示更新，不引导降级。升级后提示收起，焦点移交到连接说明入口；提示不覆盖操作结果，不阻断已有功能。比较基准为当前随包版本，不联网检查。
- 版本号新增字段在本机接入处校验，拒绝无效或恶意内容。桌面 0.8.0、扩展 0.5.0；不新增依赖或权限。
- API 依据：[runtime.getManifest](https://developer.chrome.com/docs/extensions/reference/api/runtime#method-getManifest)。
- 验证：38 项测试与真实 Electron 桌面验证通过。覆盖 manifest 实际版本上报、来源隔离、恶意版本拒绝且不污染快照、旧版未知、低/同/高版本数值比较、四段补零等价、升级入口、结果保留与焦点移交；原有定位、搜索、选择、关闭、设置及最小窗口回归通过。已检查版本提示、设置版本信息和最小窗口截图。
- Windows x64 0.8.0 已重新打包，EXE/ASAR、显示版本元数据及全部正式界面源码一致；随包扩展 0.5.0 文件一致、权限未增加，ZIP 完整性检查通过。本次改动尚未在 Windows 实机验证。
