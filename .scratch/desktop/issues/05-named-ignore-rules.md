# 命名忽略规则支持多个域名

Status: ready-for-agent
State: closed

规格见 [spec.md](../spec.md)。

## Comments

- 2026-10-18：用户要求忽略项包含名称、多个域名、多个忽略词，以便网站更换域名时复用设置。
- 范围：规则校验与旧格式读取、桌面编辑和本机保存、测试、说明、Windows 打包。core 保留域名映射接口，桌面调用时展开规则；名称不参与标题匹配，排序、预选与扩展协议保持不变。
- 每条最多 50 个域名、50 个忽略词，总计最多 100 条规则。域名在一条规则内规范化去重，跨规则重复明确报错，避免暗中叠加；保存失败保留原配置。
- 界面支持新建、编辑名称、追加或移除域名、共用忽略词、删除当前规则，以及从当前同步网站添加域名；旧设置以原域名作为名称无损读取，首次保存时转换文件格式。
- 30 项回归测试通过，覆盖旧设置迁移、校验、最大配置、原子保存及原有匹配/排序/预选/关闭逻辑。
- 桌面测试准备曾因异步写配置导致 Electron 提前就绪，已向用户说明；用户确认后，仅将测试准备改为同步写入。
- 真实 Electron 窗口验证通过：迁移后原文件未改写，多域名共用词，改名/追加域名/删除不影响其他规则，冲突和非法输入不覆盖文件，同步保留编辑与焦点，页面重载恢复；980 像素最小宽度无横向溢出。
- Windows 0.2.2 便携版已生成，包内桌面文件、core、规则模块、README 与扩展资源逐项核对一致；ZIP 完整性检查通过。Windows 实机及真实 Chrome/Edge 联调未执行。
