# 选中文字快捷添加忽略词

Status: ready-for-agent
State: closed

## Comments

- 2026-10-18：用户指定用左键选择标题中的文字，右键菜单添加为忽略词，不增加分组按钮。
- 分组标题及单行标题可选择文字；右键菜单仅在选区完整位于该标题、文字有效且有 HTTP/HTTPS 网站时提供添加。按该标题对应域名找到规则并追加，保留名称、其他域名及忽略词；新域名以域名为名称创建规则。全半角和大小写等价的词不重复添加。
- 菜单取消不写入，保存沿用既有校验与原子写入。成功后立即重新分组；排序与预选逻辑不变，自动预选关闭时保留手动选择。设置中存在未保存编辑时提示先处理草稿，不覆盖草稿。
- 搜索过滤后的分组标题仍对应原始首项的网站，不误用当前第一条显示项的域名。非网站网址、跨标题选区及无效文字不提供入口。桌面版本更新为 0.9.0，扩展保持 0.5.0。
- 验证：38 项单元/协议测试通过，真实 Electron 桌面验证通过。实际鼠标拖选文字并打开、取消原生右键菜单，不误改勾选；通过菜单回调覆盖新建规则、向多域名规则追加、全半角等价词去重、即时重新分组、关闭自动预选时保留手动勾选、草稿保护、过滤后的标题域名对应、跨标题和非网站选区排除。既有定位、搜索、筛选、关闭、设置及最小窗口回归通过，已检查选中文字截图。
- Windows x64 0.9.0 已重新打包，EXE 版本元数据、ASAR 内全部桌面源码与 README 一致，随包扩展 0.5.0 文件及权限一致，ZIP 完整性检查通过；本次功能尚未在 Windows 实机验证。
