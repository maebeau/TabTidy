- 影响桌面 IPC、模板和渲染、本机双向指令、扩展后台、版本与说明、协议/扩展/桌面测试；复用并保留前一项分组勾选功能。

- 完成 0.2.0：移除导出入口与文件保存 IPC，增加经认证的本机关闭指令/回执；扩展关闭后确认标签页已不存在，并同步剩余列表。
- 验证：22 项回归测试通过；真实 Electron 窗口通过确认/取消、取消不发送、操作中禁用、跨浏览器同 ID 隔离、分组勾选、部分失败及结果保留测试。浏览器 API 使用模拟边界，未进行真实 Chrome / Edge 与 Windows 联调。
- 已生成 `dist/TabTidy-Windows-x64.zip`；桌面关键文件与扩展资源逐字节对照源码，版本为 0.2.0，ZIP 完整性检查通过。
- 关闭可能丢失未保存内容；确认与关闭无法原子执行。关闭最后一个浏览器窗口或连接中断时，回执可能无法送达，界面报告未知并要求核对实际状态。
