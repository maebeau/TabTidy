# Windows 桌面应用与配套扩展

## 已确认范围

- 可左键选择分组或单行标题的文字，在右键菜单中直接添加为忽略词；按该标题的精确域名追加已有规则或创建规则，不重复添加等价词，不影响其他网站。取消菜单不保存，未保存的设置编辑须先处理。保存后沿用既有重新分组及预选逻辑。
- 设置页显示当前桌面及随包扩展版本，来源旁显示实际运行扩展的上报版本。低于随包或未上报时，在侧栏显示独立的升级说明和扩展文件夹入口；相同或更高版本不提示降级。版本逐段按数值比较，旧扩展兼容为未知；仅与随包版本比较，不联网检查。提示不覆盖关闭结果、不阻断已有功能，消失时保留可操作的焦点。
- 支持候选组内标题/网址搜索和“只看已选”，与来源、整组项数筛选共同生效；先归组、排序及预选再过滤，部分显示标明显示数/总数。关闭及整组勾选仅作用于显示项，隐藏手动选择保留。每行独立定位按钮通过对应扩展激活原标签页及窗口，核对来源/会话/标题/网址，支持恢复最小化窗口，旧扩展显示升级引导，离线不排队或重试。
- 正式界面采用已选定的 A 原生侧栏风格：银灰侧栏、白色内容区、蓝色主要操作及勾选、细分隔线和适度圆角。设置页沿用同一配色与规则卡片，保持主列表、筛选、排序、预选、配对及关闭交互；辅助文字对比度至少 4.5:1，Windows 使用系统字体回退。设计原型及其他方案仅保存在独立分支。
- Windows 桌面应用为操作入口，配套扩展读取正在运行的 Chrome、Edge 标签页。
- 本机处理标题和网址，复用既有 core；人工确认后通过扩展关闭已选标签页，不移动或改写页面。
- 展示候选组、原因、原始标题、网址与浏览器来源，支持自然/时间升降序、单条/整组勾选和确认关闭，移除导出入口。
- 界面采用紧凑布局：左侧独立滚动的浏览器来源与可收起的接入说明，顶部固定标题、简短统计和关闭/设置操作，排序、自动预选与数量筛选合并工具栏。去掉口号、重复统计、分组编号与原因标签，归组原因和完整标题保留悬停信息；浏览器名称仅在混合来源时逐项显示，未知时间在时间排序时统一提示。所有控制保留可访问名称、状态与必要说明。
- 首次收到来源后收起配对说明，焦点在说明内时移交给展开入口；后续同步不覆盖用户展开状态。自动同步不重复显示成功提示，也不覆盖关闭结果或错误。同一浏览器多个配置仍以来源标识区分。
- 主列表向下滚动超过 300 像素后显示右下角“回到顶部”图标按钮，支持鼠标和键盘；默认平滑返回，减少动态效果时直接返回，焦点移至页面标题，勾选保持不变。
- 主界面按每组全部标签页数量筛选，包含建议保留项。支持最少/最多项数，默认最少 2、最多不限，应用后生效；重置恢复全部分组，重载或重启恢复默认。只接受不小于 2 的整数，最多不可小于最少，无效输入保留已应用的条件。与浏览器来源联合生效，同步后重新判断；启用条件后统计及关闭仅包含显示分组，隐藏分组手动选择保留；关闭期间禁用筛选。
- 各浏览器配置独立连接、合并展示，相同浏览器 tab ID 不冲突；同步替换该来源的整个快照。

## 首版实现

- Electron + 原生 HTML/CSS/JavaScript，目标 Windows 10/11 x64 便携文件夹，扩展随包提供。
- 桌面启动本机回环服务；扩展以桌面显示的随机连接码认证，标题与网址只发往 127.0.0.1。
- 扩展读取全部普通窗口标签页。首次在弹窗配对并同步，此后标签页创建、标题/网址更新或关闭时同步；配对信息和来源标识持久保存。连接失败或桌面重启后使用浏览器闹钟自动恢复，未配对时不建立闹钟；扩展后台启动时检查并重建丢失的闹钟。扩展要求 Chrome / Edge 120 及以上，重试周期约 30 秒，时机受后台调度与休眠影响。
- 桌面左侧可选择全部或单个浏览器配置来源，列表、统计、关闭仅作用于当前范围；切换来源保留隐藏来源的手动选择，关闭操作中禁用切换。来源卡片显示指令连接的状态，断线时标明显示旧清单；仅连接状态变化不重建候选组、不打断焦点。
- 不采集页面正文、Cookie 或历史记录，不做云端上传，不申请隐身模式权限。
- 打开时间无法从浏览器接口可靠补回，扩展发送未知时间；界面明确标注，时间排序沿用 core 的保守预选规则。
- 主界面提供自动预选开关，首次默认开启，本机记住偏好；关闭只取消自动勾选，保留手动勾选/取消，同步、切换排序及更新规则均不新增自动勾选。重新开启对非手动项采用当前排序建议。手动选择仅保留本轮，重载/重启后重新计算。
- 手动勾选在同一轮后续同步中保留；自动预选开启时主动切换排序会重新预选并提示，关闭时排序保留手动选择。
- 右上角齿轮图标打开原生模态设置对话框，左侧设置项、右侧设置内容；已有“忽略规则”分类，规则以卡片展示名称、域名和忽略词，通过按钮添加、编辑、删除。添加/编辑在右侧表单中完成，保存返回卡片列表，取消保留原规则。默认关闭，支持返回按钮及 Esc、键盘焦点限制与返回入口，关闭保留本轮未保存草稿。设置内容在最小窗口中可滚动，操作结果在设置内显示，不被后续浏览器同步覆盖。
- 用户可保存命名忽略规则，每条包含名称、多个完整域名、多个网站/板块忽略词；名称仅用于管理，所列域名共用忽略词，新旧域名可并存。同一域名不能用于不同规则，域名间不自动继承。
- 规则在本机用户目录持久化，后续同步及重启自动生效；保存/删除后重新分组并提示，自动预选开启时重新预选，关闭时保留手动选择；原始标题保留用于显示、排序和关闭核对。删除只影响当前规则。旧版域名映射自动读取为命名规则，以域名为初始名称；读取不改写原文件，保存时原子更新为新格式。
- 每组提供全选/取消勾选框，支持半选显示，与单条勾选、数量和关闭联动；全选包含建议保留项，后续同步保留现有标签页的手动选择及组勾选框焦点。
- 关闭必须经桌面原生确认弹窗，默认取消；按浏览器来源及扩展运行会话隔离，关闭前重新核对编号、网址与标题，跳过不存在、跳转中、隐身或已变化的页面。
- 扩展通过经认证的本机长轮询接收指令，指令与回执有唯一编号及 30 秒时限；离线不排队，超时报告结果未知且不自动重试。关闭后同步剩余标签页，显示成功、跳过、失败与未知数量。
- 自动重连先重新同步完整标签页清单，再恢复关闭指令连接；复用既有配对认证，不重放或自动重试关闭。
- 旧扩展缺少关闭功能所需信息时跳过关闭，提示明确说明版本过旧，并引导打开扩展文件夹、替换原目录文件、在浏览器扩展管理页重新加载后再同步；说明仅同步不会升级扩展。
- 本次不做自动更新、托盘、数据库、自动清理或商店发布。

## 验证

沿用 core 公开入口测试；新增本机 HTTP 协议测试覆盖认证、来源隔离、快照更新、恶意数据拒绝；扩展测试覆盖真实发送流程的外部浏览器接口；桌面通过实际窗口验证同步后的分组、排序和勾选，检查同步后的键盘焦点保留、辅助文字至少 4.5:1 对比度。Windows 打包产物与宿主环境测试分别记录，不把 macOS 验证当作 Windows 实机验证。

关闭回归覆盖跨浏览器相同 tab ID、会话变更、网页跳转及标题变化、隐身排除、部分失败、旧扩展兼容提示、超时及过期回执拒绝；桌面覆盖取消不执行、默认取消、操作中禁用、结果保留和分组勾选联动。
