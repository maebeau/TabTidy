# Windows 桌面应用与配套扩展

## 已确认范围

- Windows 桌面应用为操作入口，配套扩展读取正在运行的 Chrome、Edge 标签页。
- 本机处理标题和网址，复用既有 core；不关闭、移动或改写浏览器标签页。
- 展示候选组、原因、原始标题、网址与浏览器来源，支持自然/时间升降序、人工勾选和导出已选项。
- 各浏览器配置独立连接、合并展示，相同浏览器 tab ID 不冲突；同步替换该来源的整个快照。

## 首版实现

- Electron + 原生 HTML/CSS/JavaScript，目标 Windows 10/11 x64 便携文件夹，扩展随包提供。
- 桌面启动本机回环服务；扩展以桌面显示的随机连接码认证，标题与网址只发往 127.0.0.1。
- 扩展读取全部普通窗口标签页。首次在弹窗连接并同步，此后标签页创建、标题/网址更新或关闭时同步；桌面重启后可在扩展再次手动同步。
- 不采集页面正文、Cookie 或历史记录，不做云端上传，不申请隐身模式权限。
- 打开时间无法从浏览器接口可靠补回，扩展发送未知时间；界面明确标注，时间排序沿用 core 的保守预选规则。
- 手动勾选在同一轮后续同步中保留；用户主动切换排序时重新预选并提示。
- 本次不做自动更新、托盘、数据库、自动清理或商店发布。

## 验证

沿用 core 公开入口测试；新增本机 HTTP 协议测试覆盖认证、来源隔离、快照更新、恶意数据拒绝；扩展测试覆盖真实发送流程的外部浏览器接口；桌面通过实际窗口验证同步后的分组、排序和勾选，检查同步后的键盘焦点保留、辅助文字至少 4.5:1 对比度。Windows 打包产物与宿主环境测试分别记录，不把 macOS 验证当作 Windows 实机验证。
